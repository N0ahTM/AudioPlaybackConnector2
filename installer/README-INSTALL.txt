AudioPlaybackConnector2
=======================

This bootstrapper has installed the app as a per-user MSIX package.

Manage or uninstall the app via:
  Windows Settings > Apps > Installed apps > AudioPlaybackConnector2

Updates:
  The .appinstaller file published with each GitHub release enables
  automatic update checks. You can add it at any time by opening:
  https://n0ahtm.github.io/AudioPlaybackConnector2/AudioPlaybackConnector2.appinstaller

Source code and support:
  https://github.com/N0ahTM/AudioPlaybackConnector2
